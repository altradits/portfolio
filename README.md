## ⚡ Features

- **Dynamic Interactive Hero**: High-contrast typography showcase with multi-discipline slide transitions and deep ambient grain overlay.
- **Web Development Portfolio**: Showcases frontend architecture, full-stack systems, performance optimization, and AI automations.
- **Photography & Visual Storytelling**: Curated gallery covering architecture, street, portrait, and atmospheric light photography with high-res lightbox modals.
- **Videography Showcase**: Cinematic rhythm and concept-driven motion reel presentation.
- **Interactive Modals**:
  - **SEO Quick Test Modal**: Instant audit tool analyzing page speed, semantic headers, meta tags, and mobile accessibility.
  - **Contact & Inquiry Modal**: Direct client contact channel.
  - **Legal Modal**: Comprehensive Impressum and Datenschutz (Data Protection) compliant with European DSGVO standards.
- **Bilingual Support**: Instant live language switching between English (`EN`) and German (`DE`).
- **Performance Optimized**: Sub-second load times, glassmorphism UI styling, zero layout shifts, and responsive touch controls.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/altradits/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev-frontend
# or run the entire workspace
npm run dev
```

### Building for Production

```bash
npm run build
```

The optimized static production bundle will be generated in `frontend/dist/`.
